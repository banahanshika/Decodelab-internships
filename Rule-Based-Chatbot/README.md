# Rule-Based Chatbot

A simple conversational chatbot built using Python as part of my Decode Labs internship.

## Features
- Responds to greetings
- Processes user input using predefined rules
- Uses conditional statements and loops
- Supports exit commands

## Technologies Used
- Python
- If-else statements
- Loops
- String handling

## How to Run

1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

   python chatbot.py

4. Type a message to interact with the chatbot.
5. Enter an exit command supported by the program to stop it.

## Learning Outcomes
- Understanding rule-based chatbot logic
- Using conditional statements
- Building an interactive command-line application
