# Simple Recommendation System

## About the Project
A beginner-friendly Python project that recommends movies based on user preferences and interests.

## Features
- Accepts user interests as input.
- Matches interests with movie genres.
- Calculates a match score for each movie.
- Sorts recommendations by matching score.
- Handles empty input and duplicate preferences.

## Technologies Used
- Python 3
- Lists and dictionaries
- Loops and conditional statements
- String manipulation and sorting

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python recommendation.py
```

4. Enter interests separated by commas, such as:

```text
action, sci-fi
```

5. View the recommended movies and their match scores.

## How It Works
The system compares the user's interests with the genres assigned to each movie. Movies with more matching interests receive higher scores and appear first.
